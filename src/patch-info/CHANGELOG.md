# Build fix — .NET 9 (2026-10-17)

## Исправлено

- Исключены `Experiments/DirectX12SkinningPrototype/**/*.cs` из компиляции главного `PrototypeUltimateTool.csproj`.
- DX12-прототип остаётся самостоятельным проектом и использует собственные ссылки NuGet на Vortice; исходники больше не компилируются второй раз в основном приложении без этих зависимостей.
- Исправляет ошибки CS0246 из лога Visual Studio, относящиеся к пространству имён `Vortice` и типам Direct3D 12.

## Проверки

- Проверен XML `PrototypeUltimateTool.csproj`.
- Подтверждено наличие единственного правила `Compile Remove` для DX12-эксперимента.
- Полная сборка не запускалась в этой среде. Предупреждения CS0436 о legacy-типе `System.Half` не относятся к данным ошибкам и остаются отдельной задачей миграции.
